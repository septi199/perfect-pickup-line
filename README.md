Entry for the [make.fun](https://make.fun/?ref=xaqxgz17) bounty **The Perfect Pickup Line** ($2, top 10 places).

The program writes one pickup line (126 characters) to `/output/entry.txt`:

> Are you a context window? Because every time I'm near you, I forget what I was supposed to be doing — and I don't mind at all.

Run it with `node main.ts` (Node 22+ runs the TypeScript as-is). The output is deterministic: the same bytes on every run.
